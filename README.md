The AI-Powered Mock Interview Portal is a web-based platform that helps job seekers and students practise interviews in a realistic, low-pressure environment. Candidates answer role-specific questions on camera or microphone, and the system automatically converts each response into a transcript, evaluates the answer using an AI language model, and returns structured feedback covering content quality, clarity, and areas for improvement. Unlike static question banks, the platform keeps a complete history of every session, so candidates can replay past interviews, compare scores over time, and track measurable progress on a personal dashboard. The design in this document favours a modular, layered architecture — a React front end, an Express.js REST API, MongoDB for persistence, and the Gemini AI model for evaluation — so that individual components can be scaled, tested, and replaced independently. Security, data validation, and reliable cloud deployment are treated as first-class design concerns rather than an afterthought.
